Resumen ejecutivo

RealEstateApp es un proyecto maduro y arquitectónicamente sólido. La separación física WebApp/WebApi, la Onion Architecture, EF Core Code First sobre SQL Server con migraciones reales, ASP.NET Identity con seeds obligatorios y la seguridad JWT están implementadas y verificadas con evidencia directa en el código. Las reglas de negocio críticas —aceptar oferta de forma transaccional, límite de 1–4 imágenes validado en servidor, bloqueo de edición/eliminación de propiedades vendidas, código único de 6 dígitos, cascadas de catálogos— existen y son correctas.

El proyecto no alcanza el 10 por un conjunto de desviaciones menores distribuidas: un hallazgo Media real de robustez en la carga de imágenes (se ignora NumberFailed), un patrón de concurrencia riesgoso en un catálogo, un defecto cosmético en un seed y tres detalles de la API (Swagger sin summaries, validaciones inconsistentes de Id). Ninguno rompe funcionalidad ni seguridad.

Fortalezas verificadas

  • 7 proyectos, Onion estricto, WebApp≠WebApi
  • SQL Server + Code First + migraciones
  • Seeds: 4 roles + Admin/Dev/Agente/Cliente
  • JWT completo (401/403, Bearer, roles)
  • Aceptar oferta = transacción atómica
  • Mensajes de registro literales del PDF

A corregir (Media)

  • H-05: SaveManyAsync ignora NumberFailed
  • H-CAT: Task.WhenAll sobre DbContext compartido

Impacto acotado; no bloquean el gate.

Detalles (Baja)

  • Seed Cliente: ruta de imagen malformada
  • Swagger sin <summary>
  • Validación de Id inconsistente (API)
  • GetById API reutiliza método del WebApp
  • Carrera aceptar oferta (mitigada)

Creación de propiedad — código, imágenes y validación servidorAgentPropertyService.cs · PropertyValidationService.cs
Media · H-05
Evidencia OK
Código único de 6 dígitos con bucle de unicidad (random.Next(100000,999999) + ExistsCodeAsync). Validación en servidor de 1–4 imágenes (crear y editar, contando existentes), precio/tamaño >0, descripción y ≥1 mejora requeridas, bloqueo de edición/eliminación de propiedades Sold.
Defecto
En crear (líneas 79-90) y editar (227-239) se itera solo SaveManyAsync().Files e se ignora NumberFailed. Si un archivo supera el conteo pero FileManager lo rechaza (extensión/content-type/magic bytes), la propiedad se persiste con menos imágenes de las declaradas —o con 0— sin avisar al usuario ni abortar.
Impacto
Rompe silenciosamente la regla «1 a 4 imágenes» en el caso límite de archivo aparentemente válido pero rechazado por bytes. Fix: comprobar NumberFailed > 0 y devolver ValidationResult.Failure.
Puntuación
−0.5 en el criterio de carga de imágenes

Cliente: favoritos marcar/desmarcar con validación anti-duplicado, «Mis propiedades» solo disponibles, chat bidireccional, ofertas con bloqueo si hay una pendiente / si está vendida / monto > 0. Agente: home con disponibles+vendidas propias, etiqueta de vendida, aislamiento entre agentes, conversaciones y ofertas por cliente.

Qué falta para el 10/10

Solo hallazgos concretos de código o documento. No se listan pruebas de runtime (doble clic, overposting, cascadas en BD, envío de correos): esa verificación la ejecuta el equipo y no forma parte de la evaluación de código.

  1. H-05 (Media): comprobar NumberFailed > 0 tras SaveManyAsync en crear y editar propiedad, y abortar con ValidationResult.Failure. Cierra el único hallazgo Media funcional.
  2. H-07 (Media): unificar el conteo de asociaciones de PropertyTypeService (y SaleType) al patrón agrupado en memoria de ImprovementService, eliminando el Task.WhenAll sobre el DbContext scoped.
  3. H-06 (Baja): corregir "Img/Users667d…" → "Img/Users/667d…" en DefaultUserCustomer.
  4. H-API-01 (Baja): añadir <GenerateDocumentationFile> al csproj y comentarios <summary> a los endpoints para completar la documentación Swagger.
  5. H-API-02 / H-API-03 (Baja): homogeneizar la validación de Id en la API y usar un método de consulta específico de la API en PropertyController.GetById.
  6. Verificación textual literal (documento): cotejar palabra por palabra los mensajes del sistema de la WebApp contra los «mensajes sugeridos» del PDF y ajustar los que difieran.
